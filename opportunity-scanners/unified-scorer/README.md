# Unified Opportunity Scorer

Master dashboard aggregating and ranking opportunities from all 6 scanners.

## Scoring Framework

### Weighted Factors

- Revenue potential (30%)
- Time to revenue (25%)
- Competitive moat (20%)
- Execution complexity (15%)
- Risk level (10%)

## Dashboard Views

1. **Top Opportunities** - Highest scored across all scanners
2. **Quick Wins** - Low complexity, near-term revenue
3. **Long Plays** - Strategic bets with higher upside
4. **Category Leaders** - Best in each scanner vertical

## Current Status

Active - aggregating data from all scanners.

## Key Metrics

- Total opportunities tracked
- Average score by category
- Conversion rate (scored → pursued → revenue)
- Portfolio balance across risk/reward profiles
