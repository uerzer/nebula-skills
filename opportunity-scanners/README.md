# Opportunity Scanner Intelligence System

Automated revenue opportunity detection across 6 strategic channels.

## Scanner Structure

Each scanner has its own folder with:
- Python script (core logic)
- outputs/ (execution results)
- README.md (scanner-specific docs)

## 6 Active Scanners

1. **crypto-arbitrage/** - DEX/CEX spreads, MEV opportunities
2. **ai-agency-leads/** - HVAC, dental, roofing automation leads
3. **viral-trends/** - Product Hunt, HN, Reddit early signals
4. **enterprise-pricing/** - RFP intelligence, $50K-150K deals
5. **micro-saas/** - Pain point validation, ICP research
6. **unified-scorer/** - Master dashboard ranking all opportunities

## Backup Schedule

- Hourly: Scanner outputs and execution logs
- Daily: Memory context and research summaries
- On-demand: Manual backups via automation trigger
